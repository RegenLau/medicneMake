# 希息药事 MG 素材制作规范

供外包制作和内部验收使用。由项目方确认本规范后再发给外包。涉及具体药品、人体机制、用药动作和适用条件的画面，交药师确认脚本和分镜后再制作。

## 交付文件

| 文件 | 要求 |
| --- | --- |
| After Effects 工程 | 交付 `.aep`，整理图层与合成，包含工程所需的自制矢量素材。标注 AE 与导出插件版本。 |
| Lottie JSON | 通过 Bodymovin 导出，保留独立的 `.json`。画布建议 1280×720，16:9，统一 24 fps。动画无声。 |
| 预览 MP4 | 1280×720，24 fps，按 JSON 的动作顺序导出。用于制作方与药师确认造型、动作和节奏。 |
| 素材信息 | 提供名称、一句适用描述、2–5 个标签、色值映射、各标记点及开始时间、原始来源和授权。第三方素材附原始链接及授权原文。 |

- 主要动作保留在画面中央安全区，四周至少留 5% 空间。上方预留标题和要点位置。工作台把文字加在独立叠加层。
- 只交付矢量形状和必要的预合成。移除文字图层、位图、音频、表达式、外部链接和随机动画。避免图层和蒙版叠加过多。
- 单个 JSON 上限 1 MB，所有预合成累计不超过 200 个图层。建议主体动作 2–4 秒，循环段末帧应自然接回首帧。
- 相同时间点多次打开，元素位置、路径、颜色和透明度应一致。随机变化改成明确关键帧。文件名使用小写英文、数字和短横线。

## 颜色

导出文件用以下六种源色。工作台按配色映射切换医疗蓝和暖色主题。透明度可单独调整，底色优先透明。

| 源色 | 工作台变量 | 用法 |
| --- | --- | --- |
| `#1A73E8` | `--v-primary` | 主体、关键动作 |
| `#DBE8FF` | `--v-primary-soft` | 局部底板、辅助形状 |
| `#122D4C` | `--v-ink` | 轮廓、主要线条 |
| `#0E9D65` | `--v-green` | 核对、通过 |
| `#E6592D` | `--v-coral` | 风险、高亮 |
| `#FFFFFF` | `--v-card-bg` | 中性填充 |

## 标记点

| 标记名 | 用法 |
| --- | --- |
| `intro` | 需要出现的开场动作，播一次。 |
| `loop` | 可以无缝循环的动作段。 |
| `outro` | 在口播结束前播放的收尾。 |
| `sfx:scene-in`、`sfx:item-focus`、`sfx:beat-in` | 对应动效入场、聚焦或新一拍。 |
| `sfx:check`、`sfx:warning`、`sfx:outro` | 对应核对、警示或收尾。标记点对准画面变化的第一帧。 |

使用带时长的 After Effects 合成标记设置 `intro`、`loop`、`outro`，顺序一致且区间互不重叠。开头和结尾各一段，只有中间循环。单次动作无需人为加三个标记，工作台会按分镜长度调速和定格。

## 第一批场景

| 序号 | 场景 | 画面要点 |
| --- | --- | --- |
| 1 | 吞服药片 | 药片与水杯，用简化动作表示吞咽。 |
| 2 | 药片进入胃部并溶解 | 食道到胃的路径，药片逐渐散开。 |
| 3 | 肠溶片在肠道释放 | 到达肠道后打开外层，前后动作有区分。 |
| 4 | 血管扩张 | 血管示意截面变宽，适用药物由脚本指定。 |
| 5 | 血压计读数 | 袖带、测量和显示区，数字用叠加层。 |
| 6 | 血糖波动 | 用无文字曲线表示变化，保留轴与数字叠加位置。 |
| 7 | 退烧 | 体温计示意变化，画面不预设疗效或时间。 |
| 8 | 滴眼 | 瓶口、液滴和眼部关系，由药师确认取景和细节。 |
| 9 | 吸入 | 吸入装置和气流方向。按设备类型分别确认动作。 |
| 10 | 皮肤涂抹 | 由点到面轻抹，保留涂抹部位的叠加位置。 |
| 11 | 缓释 | 随时间逐步释放的颗粒示意。 |
| 12 | 药物相互作用 | 两个药物图形与一个受影响环节，具体关系由脚本定义。 |
| 13 | 抗生素作用于细菌 | 简化细菌示意。按选定药物的作用机制拆镜，由药师确认。 |
| 14 | 过敏反应 | 通过简化人体图标显示常见警示部位。 |
| 15 | 肝脏代谢 | 器官示意与路径改变，留出标注空间。 |
| 16 | 肾脏排泄 | 肾脏示意及明确流向。 |
| 17 | 漏服时间线 | 时间线、节点与回到计划的动作。文本由叠加层呈现。 |
| 18 | 药箱整理 | 包装、分区摆放和逐件核对。 |
| 19 | 儿童按体重给药 | 体重秤和说明书并列，剂量留给经过审核的叠加层。 |
| 20 | 查找说明书 | 展开说明书并聚焦某一栏，栏目名称由叠加层绘制。 |

交付前请核对冷暖两种主题、首末帧、循环接缝、标记点、图层数量和离线预览。交付版本应和药师确认的分镜对应。
