# 希息药事 · 医疗科普动效设计规范（Motion.md）

> 参考 OpenMotion `Motion.md`、`openmotion-director` 与 `openmotion-hand-drawn-explainer` 的动效编排体系，结合医院药师科普视频的「外框信息架构 + `.media-slot` 隔离舞台」定制。

## 1. 核心节奏与缓动分级（Timing & Easing Tokens）

避免整幕所有元素用同一套匀速或单一缓动，按视觉重量分层：

| 动效层级 | 推荐时长 | 推荐 GSAP 缓动 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **微交互 / 徽章弹入** | `0.25s – 0.35s` | `back.out(1.4)` | 勾选图标、警示徽章、数字标签、步骤序号 |
| **主卡片 / 标题入场** | `0.38s – 0.50s` | `power3.out` / `expo.out` | 顶部标题、要点卡片、对比栏、收口胶囊 |
| **矢量路径描边（DrawSVG）** | `0.45s – 0.75s` | `power2.inOut` | 流程连线、时间轴推进、曲线释放轨迹、勾选划出 |
| **数值滚动 / 刻度推进** | `0.60s – 0.90s` | `power2.out` | 体温/剂量/间隔小时数、液面刻度上升 |
| **柔和强调（Emphasis）** | `0.30s – 0.45s` | `sine.inOut` | 重点卡片轻抬、高亮描边、安全提示微脉冲（`scale ≤ 1.04`） |

### 节奏纪律
1. **起手留呼吸**：首元素可在 `0.05s – 0.12s` 启动，避免 `t=0` 零延迟生硬跳切。
2. **交错入场（Stagger）**：同类列表卡/步骤节点使用 `stagger: 0.10 – 0.14`；多条辅助描边线使用 `stagger: 0.04 – 0.06`。
3. **口播对齐**：优先读取 `api.cues[i].start` 作为分阶段入场偏移，让视觉变化落在实际讲到该句的节拍上。
4. **充足阅读停留窗（Hold Window）**：所有核心元素须在 `duration * 0.72` 之前完成入场，结尾保留至少 `1.2s` 的稳定静止阅读期（不急促退场，方便观众看完重点，也利于离线渲染帧复用）。

## 2. 四拍叙事编排顺序（Narrative Choreography）

遵循 **Context → Structure → Detail → Verdict** 的视觉引导顺序：
1. **定调（0% – 15%）**：顶部 kicker 徽章 + 标题与装饰短线落位，建立本幕主题。
2. **骨架（15% – 38%）**：主体容器（如对比双栏、时间轴底轨、左侧机理图框）出现，或通过 `DrawSVG` 画出主流程路径。
3. **展开（38% – 70%）**：要点卡片、图标徽章、数值计数或勾选记号按 `api.cues` 节拍依次点亮。
4. **收口（70% – 100%）**：底部结语胶囊或重点高亮强调，随后保持画面稳定直至幕末。

## 3. 医疗科普视觉高级感守则（Anti-Clutter Craft）

1. **干净克制的底纹背景**：
   - 使用内置 `.mc-canvas`（自带轻柔点阵与主题光晕）、`.mc-canvas.is-grid`（精致医疗网格）或 `.mc-canvas.is-paper`（柔和手绘底纹）。
   - **禁止**在画布角落随意堆砌大面积色块圆斑。
2. **复用 36 枚精绘医疗线性图标（禁止手画丑陋简笔画人物）**：
   - 直接使用 `<span class="mc-icon" data-icon="pill"></span>`（HTML）或 `<g data-icon="shield" ...>`（SVG），自动注入精绘线性矢量图标并继承 `currentColor`。
   - **严禁**用圆形、弧线、黑点徒手拼凑人物五官、笑脸或火柴人（外框已有药师主讲人）。
3. **信息密度与安全留白**：
   - 同屏视觉焦点不超过 **3 组**，四周安全内边距 ≥ `24px`，留白占比 ≥ `22%`。
   - 标题 `24–30px`（`font-weight: 800`）、卡片标题 `19–22px`、说明正文 `15–17px`（`--v-ink-soft`）、大数字 `44–56px`（`tabular-nums`）。
4. **终态可见原则**：
   - 静态 HTML/SVG 默认处于完整可见的终态排版（不要把主卡片在 CSS 里写死为 `opacity: 0`），入场隐藏统一交给 `tl.from(...)`。
5. **只用真实主题 CSS 变量**：
   - `--v-primary` / `--v-primary-deep` / `--v-primary-soft` / `--v-ink` / `--v-ink-soft` / `--v-card-bg` / `--v-card-border` / `--v-green` / `--v-green-soft` / `--v-amber` / `--v-amber-soft` / `--v-coral` / `--v-coral-soft`。

## 4. 语义音效同步（`api.sfx`）

- 在 `api.setup((tl, gsap) => { ... })` 中可调用 `api.sfx(秒数, 类型)`，让关键视觉节点在导出 MP4 时自动对齐素材库音效包（`soft` / `kenney`）：
  - 支持类型：`item-focus`（要点弹出，别名 `pop`）、`check`（勾选确认）、`warning`（警示提醒）、`cross`（错误划叉）、`count`（数值定格）、`draw`（路径描边）、`flip`（翻转切换）。
- 遵循克制原则：每幕点缀 `1–3` 个真正需要强调的节拍，工作台合成阶段会自动按优先级去重（相邻间隔 `≥ 0.35s`，每幕最多 4 个）。
