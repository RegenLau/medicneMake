# 医疗科普 Lottie 素材

这批素材包含 8 个 IconKing 原始 Lottie JSON。原始动画时长约 1.75–2 秒。

解压后，在工作台中打开「素材库 → Lottie → 上传 Lottie」，选择一个 JSON 文件。上传外部素材时，填写下表的原始链接和页面授权原文。

来源和署名填写 IconKing。页面授权原文为 `Free for personal & commercial use`。许可允许把动画用于个人或商业项目，包括视频，并限制把原始文件作为独立产品再分发、转售或转授权。详见 [IconKing 服务条款](https://www.iconking.net/terms)。
